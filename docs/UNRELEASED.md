## 变更

- 修复 WPS 新式文件选择窗口不弹出最近目录快捷栏：兼容原生标题为空、辅助功能接口省略取消按钮和文件类型下拉框的 Kcfd 窗口，通过专用窗口结构、文件类型标签、可写文件名及打开/保存按钮共同确认目标。

- 文件选择窗口出现时，目录助手默认只显示底部小条和最近目录快捷按钮，不自动展开详细列表；新增“最近”入口，与“收藏”一样点击后展开，输入搜索词时显示搜索结果。
- 收紧文件对话框自动识别：WPS 启动页/文档主窗口不再进入 UI Automation 查询；过滤后台应用窗口事件，按窗口和进程保留失败冷却，前台切换不再清零。识别改为隔离子进程，查询内部 8 秒超时、外部 10 秒兜底并回收子进程；保留打开/保存窗口自动展开最近目录。标准控件优先原生定位，跳转复用已核验的文件名框，减少重复整窗查询。
- 标准 Windows 文件窗口以原生地址栏及焦点核验跳转；未确认地址栏时停止操作，禁止退回文件名框发送 Enter，避免“另存为”误提交原文件名。

- 统一弹出面板外观：主面板、圆环轮、左滑动作面板、对话框目录栏共用一套颜色与字体（新增 `UiTheme`），中文界面统一用微软雅黑 UI。选中条目统一为浅蓝圆角底加主色描边；主面板当前标签／分组改为浅蓝底加主色指示条，与圆环轮一致。对话框目录栏补上圆角。
- 手势面板按方向滑入：右滑面板从左往右、左滑动作面板从右往左（约 120ms，系统关闭界面动画时不播放）。主面板底栏显示“点击或 Enter 执行”；动作面板底部按状态显示提示：拖动中为“拖到动作上松手执行”，停留后为键盘说明。
- 动作面板停留后支持键盘：↑↓ 在栏内移动、←→ 切换 Prompt／工具栏、Enter 执行、1-3 执行“最近”中的对应项；鼠标悬停与键盘共用同一高亮。

- 修复普通 Windows 文件选择窗口未自动出现目录助手：支持“打开”分体按钮及标准文件名、文件类型、确认/取消控件 ID，兼容选择/上传等自定义按钮文字。与 WPS 一样自动附着底部并展开最近目录，不额外打开文件管理器。

- 文件对话框出现时主动触发目录助手识别，并自动展开最近目录，保留文件名输入焦点；控件延迟就绪时快速重试，不再等 3 秒。所属窗口关闭导致助手被销毁时可自动重建，无须点击托盘图标。

- 轮盘和经典面板的文件夹列表默认按累计使用次数降序排列，同次数按最近使用、原手动顺序排列；统计持久保存，从本版本开始累计。设置 → 列表与工具可关闭频率排序；对话框底栏仍按最近使用排列。

- 对话框底栏改为最近目录，成功跳转后置顶并去重；空搜索展示最近目录，仅点击“收藏”展开收藏。支持读取 Opus 收藏、使用 Quickstart 独立收藏或合并去重；齿轮和设置页可管理来源及本地收藏。只读接入 Opus 最近目录及当前源标签，不修改 Opus 配置。

- 修复目录助手展开收藏或搜索结果时跳到屏幕顶部：输入栏保持原位置，空间不足时结果向上展开。取消全局置顶并绑定所属对话框；根据实际前台窗口隐藏，避免切换应用后仍遮挡其他窗口。

- 本地搜索默认快捷键冲突时自动尝试备用组合并保存，提示实际可用快捷键；自定义组合保持不变。注册失败提示增加具体按键、修改入口和仍可使用的搜索入口。

- 文件对话框增加自动附着的底部搜索与收藏小条：显示常用收藏、展开全部收藏、Everything 文件夹搜索、单击结果跳转，跟随窗口移动并在切换应用时隐藏。目录助手始终绑定原对话框，错误时不回退到资源管理器；WPS 所属窗口经中键菜单／主面板呼出时也解析到实际文件对话框。
- 新增打开／保存对话框目录跳转：内置搜索自动识别来源对话框并默认筛选文件夹，主面板／轮盘文件夹收藏也可跳转；保留原文件名，不自动提交打开或保存，支持设置关闭。
- 适配 WPS 的 Qt 文件名组合框焦点及另存为时自动去扩展名的行为；实测 WPS 文字 12.1.0.26885 的打开／另存为、Windows 标准打开／保存，含中文、空格、#、% 目录。标准窗口使用 Ctrl+L 地址栏入口，避免 Alt+D 被其他工具接管。
- 发布包保留完整运行库（仍为自包含单 EXE），避免 UI Automation 在裁剪发布下识别失败或崩溃；文件体积相应增加。对话框识别错误不再被搜索结果状态覆盖。
- 新增 Quickstart 内置本地文件搜索窗口：直接通过 Everything IPC 读取索引，支持输入防抖、取消过期查询、每页 100 条、文件/文件夹筛选、名称/修改时间/大小排序，以及打开、定位、复制路径和加入收藏；保留跳转 Everything 原窗口入口。
- 新增本地搜索独立快捷键（默认 Ctrl+Alt+Space，可修改或禁用），主面板放大镜、主面板/轮盘 Ctrl+F 和托盘菜单均可进入。左滑 Everything 工具改为在内置窗口显示选中文字的搜索结果；无选中文字时打开空搜索框。
- 新增鼠标中键单击入口，选择快捷启动（遵循经典/轮盘设置）、动作面板或本地搜索；设置 → 快捷启动可单独关闭中键接管，保留左右划手势配置。
- 右滑启动器统一为松手停留、左键点击或经典面板内按 Enter 执行；经典列表为推荐样式，轮盘仍可选。左滑动作面板保持原有拖动选择方式。
- 轮盘按点击切换分类与分组，删除持续锁定标签的路径保护和鼠标移动驱动的自动滚动；空白、行间距和滚动条不再吸附执行条目。
- 轮盘移除 80 条加载限制，使用滚轮或方向键浏览；只为可见条目请求图标，文件和程序图标在后台读取。
