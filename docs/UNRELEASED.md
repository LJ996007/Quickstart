# Unreleased

> 自 **上一个已发布版本** 以来的改动先记在这里。
> **默认不升版本号**。只有明确要求「升版本 / bump version」时，才把本文件条目汇总进新版本说明并清空。

## 变更

- 优化弹窗流畅性：目录助手的位置轮询不再反复改写未变化的文字和列宽；主面板开启双缓冲，圆环动画复用原生绘制缓冲；启动后分阶段隐藏预热常用面板和本地搜索，不弹出窗口、不抢焦点。
- 从最近目录打开本地浏览时，首次显示前就准备好目录导航布局，避免先闪出搜索布局再跳变；文件类型图标跨页复用，缩放变化时统一清理重建。
- 最近目录菜单增加上一级名称；文件选择弹窗的目录快速按钮分两行显示当前目录及上一级，展开列表显示父目录名称。长名称按可用宽度自动省略，完整路径保留在悬停提示中，便于区分不同项目下的同名目录。
- 修复本地搜索在拖动列表与预览的分隔条、滚动列表后出现内容空白的问题，补齐单元格局部重绘并保留整行重绘及悬停防闪烁。
- 修复圆环面板在分辨率或缩放切换后字体过大、分类文字拥挤的问题；字体与几何统一缩放，按工作区收窄列表和调整可见行数，保留完整圆环及滚动访问。
- 本地搜索默认不置顶，标题栏增加置顶开关；屏蔽原生列表的鼠标热跟踪重绘，保留路径提示，消除名称悬停闪烁。
- 普通启动及重复启动均静默驻留托盘，手势面板改为按需创建，避免启动时弹出面板。
- 中键搜索条新增“最近目录”，读取 Windows 最近使用记录中的文件夹及文件所在目录，选择后直接在内置本地搜索窗口浏览，不调用默认文件管理器。
- 修复本地搜索列表鼠标移入其他行时的重绘闪烁；双击文件或使用预览区打开后保留搜索窗口，方便继续浏览。
- 文件预览顶部的文件名、复制及打开按钮合并为一行，固定工具栏高度，修复预览上方空白过高的问题。
