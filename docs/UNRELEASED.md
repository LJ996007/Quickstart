## 变更

- 轮盘文件夹行新增展开箭头，可在紧凑目录栏中逐级浏览，按名称查找文件和文件夹，并选择是否搜索子目录。
- 目录浏览按文件类型显示系统图标，顶部路径栏右侧可拖动窗口。
- 加宽轮盘文件夹和目录浏览的右侧展开区。目录内容先按最近使用时间排序，未使用的条目按最近修改时间排序；轮盘「最近」显示条目实际所在的上一级目录。
- 目录浏览改为四角圆角窗口，与其它弹出面板一致；列表右键可复制文件或文件夹（可直接粘贴到资源管理器）以及复制完整路径，对应 Ctrl+C 与 Ctrl+Shift+C。
- 目录浏览的点击方式改为：单击文件在旁边的独立预览窗中打开（内置预览，按文件类型 / 图片比例自动定尺寸并保证可读），双击用默认程序打开，Ctrl+单击在资源管理器中定位该文件或文件夹。预览窗带「钉在最前面」按钮：钉住后关闭目录列表也一直留在最上端，方便逐份核对内容；右上角可直接关闭。
- 修复本地搜索的内置备用快捷键再次冲突时无法切换的问题，自动尝试其余可用预设。

- 独立预览窗可拖动边缘调整大小，换文件时保留手动窗口尺寸；工具栏收窄，文档按可用宽度适配，超宽表格保留横向滚动。Word、Markdown 和表格选区旁新增「复制纯文本」。
- 加快中键面板、手势列表和轮盘的呼出与重绘。用过文件预览后，下次启动会在托盘空闲时预热预览引擎。目录和本地搜索中单击文件即可开始预览，连续切换会取消上一次读取，拖动图片预览时复用已解码的尺寸。
- 在目录浏览或本地搜索中预览文件后，Quickstart 会将已显示的文件加入 Windows 最近使用记录，可从列表和轮盘的「最近」再次打开。
